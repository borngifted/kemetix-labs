# Kemetix Labs

Official website for Kemetix Labs — Precision. Performance. Potential.

Built with React 19, Vite, Tailwind CSS 4, and shadcn/ui.

## Development

```sh
pnpm install
pnpm dev
```

## Build

```sh
pnpm build
```

Static output lands in `dist/public/`. The live site is served from the `gh-pages` branch via GitHub Pages.
